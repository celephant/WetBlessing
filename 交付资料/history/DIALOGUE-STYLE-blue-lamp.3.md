# 台词与文本演出：主动暧昧执行口径

## 写作范围

采用用户澄清后的 v3.0 文风：参考主动邀请、相互逗弄、短句停顿与心跳感，实际动作以已核验图片为依据。8 步示例不是固定流程；当前逐场修订覆盖既有 83 个节点。图片没有呈现的动作，不因为示例写过就补进文案。

这是一份文案编辑指导，不新增播放器交互或剧情状态机。镜头先决定可写动作和现场人物，再决定谁主动、谁接话、最后一句如何留下期待。空镜写短独白或旁白，不凭空安排角色站在镜头里。

## 台词节奏

- 一句做一件事：挑明眼前动作、接住对方的试探、给出更直接的邀请。避免每场都重复同一个三段公式。
- 台词以口语短句为主；省略号统一为 `……`，用来标记犹豫、藏不住的笑或认真回答前的停顿。
- 心跳拟声使用纯日文假名，如 `トクン、トクン……`、`ドクンッ……`。只在确有节奏作用时使用，不给每句硬塞音效。
- `♡` 倾向轻松逗弄，`♥` 倾向明确心意。空镜、信息交代、普通多人谈话不强行放心形。符号不作为数值阶段或付费暗示。
- 内心独白使用全角括号 `（……）`；通过目光停顿、手指收紧、脸颊发暖、呼吸和心跳体现紧张，少写解释立场或总结道理的长段落。
- 图中已经发生的牵手、拥抱、亲吻可写当下或紧接其后的对话；未出现的连续动作不当作视觉核验事实。对白属于创作，观察记录属于证据，两者分开保存。

## 选项与进度

选项使用能表达意图的动作短语，并准确提示实际去向。空镜中的回想明确标成回想；不能把跨场景跳转标成一个并不存在的现场触碰。当前 9 处选择的目标和效果没有改动，后续仍需完成独立路线与章节编排。

`content/story.json` 是唯一可编辑源，当前故事版本为 `blue-lamp.3`。修改后运行 `npm run story:generate`，再运行 `npm run check` 与 `npm run build`。现有自动校验负责重复长句、说话人、配图与引用一致性；文风自然度仍需内容审阅。
